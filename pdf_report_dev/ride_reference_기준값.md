# 기준 데이터 — ride_reference.txt

`test/fixtures/ride_reference.txt`. 원본 TUNE 리포트(`docs/reference/`)를 만든 실제
측정 데이터다. 합성 프로파일 대신 이걸로 회귀를 고정한다.

## 출처

**원래 측정 ID 는 `H6N1AP65` 였고 파일 이름도 `H6N1AP65.txt` 였다.** 내용이 순수
숫자열이라 현장을 가리키는 식별자가 파일 이름뿐이었고, 저장소 공개 범위와 무관하게
안전한 쪽을 택해 `ride_reference.txt` 로 바꿨다. 파일 내용은 한 바이트도 바뀌지
않았다(md5 `edba923e130c9754a7da0e5c10e66c2f`). 원본 리포트나 사내 기록과 맞춰
봐야 할 때 이 ID 로 찾으면 된다.

## 포맷

```
EVIMP1          형식 태그
256             샘플레이트 (Hz)
-0.929 0.919 -1.267 45.212      X  Y  Z  소음
...
```

4열이고 **소음 열이 있다.** 앱이 쓰는 `OTIS-VIB3` 는 3열이라 다르다. 나중에 소음
수집이 붙어 `formatId` 가 `EVIMP1` 로 바뀌면 이 포맷과 같아진다.

- 데이터 행 11,388개, 44.48초
- 줄바꿈이 CRLF 다. 파서가 `\r` 를 남기지 않는지 확인할 것

## 기대값

프로토타입 `derive_kinematics()` 가 이 파일에서 내는 값이다.

| 항목 | 값 |
|---|---|
| 행 수 | 11,388 |
| sampleRate | 256.0 Hz |
| maxSpeed | 1.743390961 m/s |
| distance | 57.093948064 m |
| speed[0] | 0.0 |
| speed[-1] | 0.0 |
| 소음 평균 (0 제외) | 45.8044 dBA |
| 소음 최대 | 65.6000 dBA |

원본 리포트가 적은 값은 최대 속도 1.75 m/s · 운행 거리 57.3 m 다. 위 계산이
각각 0.4% · 0.36% 낮은데, 원본이 어떤 반올림과 구간 산정을 썼는지는 모른다.
**원본과 소수점까지 맞추려 들지 마라.** 회귀는 위 계산값으로 고정하고, 원본과의
차이는 1% 이내인지만 확인한다.

`accel[0]` 과 `accel[-1]` 은 평균 제거 후의 잔차라 0 이 아니다(각각 -0.0124,
-0.0050). 여기에 단언을 걸지 마라 — 합성 프로파일과 달리 실측은 양 끝이 정확히
0 이 되지 않는다.

## 주의

끝을 잘라내면 `distance` 가 달라진다. 테스트 속도 때문에 줄이고 싶으면 파일을
자르지 말고, 별도의 짧은 픽스처를 만들고 기대값을 따로 뽑아라.

이 파일은 실제 현장 측정 기록이고 원본 리포트에 OTIS 기밀 표기가 있다. 저장소가
외부에 열려 있다면 그대로 커밋할지 먼저 확인할 것.
