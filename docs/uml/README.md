## 표기
- 분기 마름모 옆 `[조건]` 이 질문이고, 나가는 선의 참 / 거짓이 답이다. 병합 마름모는 둔다.
- 주황 선 = 되돌아가는 흐름, 주황 점선 틀 = 반복 구간.
- 갈퀴 표시가 있는 상자 = 호출 액션. 누르면 그 흐름의 액티비티로 간다.
- 시퀀스: 실선 화살표 = 호출, 점선 열린 화살표 = 반환 · 비동기 알림, `[조건]` = 그 조건일 때만.

## 도구
- `도구/생성기/` — 그림을 다시 만드는 생성기. `OTIS_SRC=<커밋 체크아웃> OTIS_UML_OUT=<출력 폴더> python3 build.py`.
  링크의 줄 범위는 소스의 `/// 함수:` 주석을 찾아 자동으로 정한다.
- `도구/check_diagrams.py <html...>` — 화면 밖 · 겹침 · 선 교차 · 선 관통 · 글자-선 겹침 · 조건 누락 · 막대 뜸 등 점검.
- `도구/verify_all.py <그림 폴더> <소스 폴더>` — 파일 · 내부 링크 · 소스 줄 범위 · 커밋 · 클릭 경로 · 탭 상태 점검.
- 두 점검 모두 Python + Playwright(Chromium) 필요.
