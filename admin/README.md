# 관리자용 명단 엑셀

운영자는 이 폴더의 **workers.xlsx 한 파일**을 내려받아 편집하고, 같은 이름으로 이 폴더에 다시 올린다.

1. 첫 시트의 앞 네 열을 **사번 · 성명 · 업체명 · 관리팀** 순서로 유지한다.
2. 사번과 성명은 반드시 입력하고, 사번은 중복하지 않는다.
3. `010613`처럼 0으로 시작하는 사번은 셀에 **`'010613`**으로 입력한다. 저장된 값은 텍스트 `010613`이어야 한다.
4. 엑셀을 저장하고 GitHub의 `main` → `admin` 폴더에 `workers.xlsx`를 업로드한다. 다른 이름으로 올린 파일은 자동화가 읽지 않는다.
5. **Actions → 새 버전 준비 → Run workflow**에서 `main`과 새 버전(예: `0.0.4`)을 선택한다.
6. 성공하면 **Releases**에서 만들어진 초안을 확인하고 **Latest**로 게시한다.

운영 절차·오류 안내와 개발 담당자의 최초 설정은 [자동화 설정](../docs/release_automation.md)을 참고한다. 사진을 넣는 관리자 매뉴얼은 실제 Actions 검증 후 단계별로 함께 작성한다.

GitHub의 엑셀 업로드만으로 배포되지는 않는다. 실행 버튼을 누르면 변환·APK 준비가 진행되고, 초안을 게시한 뒤 사용자가 업데이트를 설치하면 새 명단이 반영된다.

APK에는 변환된 `workers.json`만 들어간다. 엑셀은 앱 자산에 포함하지 않는다. 빌드 중 생성된 JSON과 버전 번호는 작업 폴더에서 사용하며 저장소에 자동 커밋하지 않는다.
