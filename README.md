# OTIS 승강기 진동·소음 측정 앱 (vibration_checker)

일반 안드로이드 스마트폰으로 승강기의 기계적 결함(진동·소음·속도·거리)을 검증하고,
OTIS TUNE 규격의 PDF 리포트를 생성·발송하는 앱. 기존에 전용 장비로만 하던 측정을
현장 설치 기사의 폰으로 대체하는 것이 목표다.

## 측정 흐름

1. 홈에서 현장 정보(제번 · 현장명 · 주소 · 층 · 운전 방향 · 기종)를 입력한다.
   입력은 바로 기기에 저장돼 다음에 그대로 남는다.
2. 시작 화면에서 대기 시간을 고르고 "볼륨키로 측정 시작"을 누른다. 처음 한 번은
   마이크 권한을 묻는다.
3. 휴대폰을 뒤집어 카 바닥 중앙에 놓고(휴대폰 위쪽이 출입구 기준 오른쪽), 운행이
   끝나면 볼륨키를 눌러 측정을 끝낸다.
4. 결과 화면에서 지표를 확인하고, 다른 측정과 비교하거나 메일로 보내거나 같은
   조건으로 다시 잰다.
