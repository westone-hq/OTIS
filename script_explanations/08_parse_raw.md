# 🔄 레거시 포맷 파서 (Parse Raw)

이전부터 사용되어 오던 구형 진동 장비(EVIMP1 등)에서 추출된 텍스트 형식의 과거 데이터를 현재 앱 시스템에 맞춰 변환하는 호환성 스크립트입니다.

## 📄 관련 스크립트
*   **[parse_raw.dart](file:///c:/Users/User/Desktop/OTIS/lib/adapter/parse_raw.dart)**

## ⚙️ 주요 기능 및 구현 위치

### 1. 구형 데이터 호환성 통역
- 기존 텍스트 파일이나 특정 로그 포맷으로 기록된 원본 파일을 읽어, 현재 앱에서 사용하는 `SensorSample` 또는 정형화된 데이터 배열 포맷으로 파싱(Parsing)해줍니다.

### 2. 데이터 마이그레이션 지원
- 새로 측정한 데이터 외에도 기존 측정 데이터를 앱으로 불러와 분석하거나 동일한 형태로 리포트를 생성할 수 있도록 브릿지 역할을 수행합니다.
