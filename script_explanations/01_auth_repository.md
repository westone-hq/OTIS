# 🔐 인증 및 보안 관리 (Auth Repository)

이 문서는 진동 측정 앱에 접근하는 기사님의 신원을 확인하고 권한을 부여하는 보안 시스템 스크립트를 설명합니다.

## 📄 관련 스크립트
*   **[auth_repository.dart](file:///c:/Users/User/Desktop/OTIS/lib/adapter/auth_repository.dart)**

## ⚙️ 주요 기능 및 구현 위치

### 1. 사용자 신원 확인 (사번 인증)
- `AuthRepository` 내부 함수를 통해 기사님의 6자리 사번(숫자)을 입력받고, 정해진 규격에 부합하는지 즉각적으로 검사합니다.

### 2. 세션(Session) 유지 및 상태 관리
- 내부적으로 인증 상태를 저장하여, 앱을 다시 켜더라도 매번 사번을 입력할 필요가 없게 처리합니다.
- 명시적 요청 시 안전하게 인증 상태를 초기화합니다.
